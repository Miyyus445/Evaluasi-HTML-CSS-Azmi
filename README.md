🎯 Tujuan
==========================================

Buatlah sebuah website sesuai desain yang telah diberikan.

Website harus dibuat menggunakan HTML dan CSS murni.
Tidak diperbolehkan menggunakan Bootstrap, Tailwind CSS, ataupun framework CSS lainnya.

==========================================
📌 Ketentuan
==========================================

1. Buat repository GitHub baru.

Nama repository:

evaluasi-html-css-nama

Contoh:

evaluasi-html-css-ahmad

2. Clone repository tersebut ke komputer kalian.

3. Kerjakan seluruh project sendiri.

4. Setelah selesai lakukan commit secara berkala.

Minimal terdapat 5 commit.

5. Push ke GitHub.

6. Kirim link repository di channel ini.
